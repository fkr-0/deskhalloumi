# DeskHalloumi 0.3.3

DeskHalloumi 0.3.3 is a backwards-compatible regression and repository-hygiene
release. It preserves every existing CLI, configuration, IPC, path,
application-ID, service, and `unilii-*` compatibility contract.

## Highlights

- Release archives are now verified independently of the source tree: checksum,
  safe extraction, temporary-prefix installation, all twelve primary and
  compatibility command smokes, the headless runtime contract, and clean
  removal.
- Bounded IPC readers now cover frames exactly at the 64 KiB protocol limit and
  one byte over it in synchronous and asynchronous paths.
- Generated-file replacement distinguishes failures before destination
  replacement from failures after rename but before parent-directory sync.
  Transactional i3 installation restores its previous include when durability
  cannot be confirmed.
- Clock, battery, and Tmux modules expose executable fixture sources for
  hardware- and service-free tests while retaining their production defaults.
- The detailed pre-0.3.3 implementation ledger moved to `docs/history/`; the
  root `tasks.yml` now contains concise active release work.
- Tracked archival `.bak` sources were removed from the canonical tree.

## Upgrade notes

No configuration migration is required. Existing DeskHalloumi and legacy
`unilii-*` commands, paths, environment variables, sockets, application IDs,
and generated i3 behavior remain compatible.

The tag, branch, binary assets, and crates remain separate publication actions.
Creating a local annotated tag does not imply that any remote release or
crates.io publication occurred.
